# LINE Card Assistant — `agents-cli` & Vertex AI Agent Runtime Specification

## 1. Agent Overview
- **Project Name**: `line-card-assistant`
- **Root Agent Name**: `line_card_assistant`
- **Language / Framework**: Go 1.26 (`adk_go` template, `google.golang.org/adk/v2`)
- **Primary Architecture**: ADK 2.0 Deterministic Graph Workflow (`workflowagent.New`)
- **Target Runtime**: Vertex AI Agent Runtime (`agent_runtime`) + LINE Messaging API v8 Adapter

## 2. Graph Workflow Topology
The root agent `line_card_assistant` is an ADK 2.0 `workflowagent` orchestrating three deterministic routes from `RouterNode`:

1. **`ingest` (Business Card OCR + Parallel Enrichment + HITL Loop)**:
   - `VisionOCRNode`: Multimodal Gemini 2.5 Flash extraction of structured `BusinessCard` JSON from uploaded images.
   - **Parallel Fan-Out (`AddFanOut`)**:
     - `CleanAndDedupNode`: E.164 Taiwan phone normalization (`+886-...`) and duplicate contact detection.
     - `CompanyEnrichNode`: Sub-agent `CompanyEnrichAgent` (`llmagent` + `geminitool.GoogleSearch{}`) summarizing company background and industry tags.
     - `ContextMatchNode`: Infers `MetContext` from recent user conversation history.
   - **Parallel Fan-In (`AddFanIn` -> `JoinPreviewNode`)**: Synchronization barrier merging all 3 parallel branches via `EventActions.StateDelta`.
   - `BuildPreviewNode`: Generates interactive LINE Flex Message Preview JSON.
   - `HITLConfirmNode`: Pauses execution via `workflow.NewRequestInputEvent` (`adk_request_input`) waiting for human confirmation (`action=confirm_save`) or natural-language field edits (`RouteEdit` -> `ApplyEditNode` -> cyclic re-entry to `BuildPreviewNode`).
   - `SaveCardNode`: Persists the verified `BusinessCard` and generates a personalized follow-up email draft.

2. **`search` (Hybrid Search + Broad Fallback)**:
   - `QueryIntentNode`: Parses natural-language search queries into structured `SearchFilter`.
   - `HybridSearchNode`: Executes structured + keyword search (`RouteFound` -> `FormatCarouselNode`, `RouteEmpty` -> `BroadSearchNode`).
   - `BroadSearchNode`: Fuzzy fallback search across all card tokens.
   - `FormatCarouselNode`: Renders up to 10 cards as a LINE Flex Message Carousel JSON.

3. **`email` (Follow-up Ice-breaker Email Generation)**:
   - `EmailDraftNode`: Generates a personalized Traditional Chinese follow-up email referencing `MetContext` and `CompanyInfo`.

## 3. Agent Runtime & `agents-cli` Integration
- **Entrypoint (`main.go`)**: Uses ADK Go's `universal.NewLauncher` combining `console`, `webui`, `a2a`, `pubsub`, `eventarc`, `agentengine.NewLauncher("app")`, `appinfo.NewLauncher()`, and `api.NewLauncher()`.
- **Agent Loader (`apploader.go`)**: Serves `app.NewRootAgent(ctx)` under the `/apps/app/...` route expected by `agents-cli` and Vertex AI Agent Runtime.
- **Session Persistence (`sessions/sessions.go`)**: Automatically selects `vertexai.NewSessionService` when `GOOGLE_CLOUD_AGENT_ENGINE_ID` is present, `database.NewSessionService` when Cloud SQL is configured, or `session.InMemoryService()` for local development and unit tests.
- **Observability (`observability.go`)**: Exports OpenTelemetry traces and logs over OTLP HTTP to `telemetry.googleapis.com` with `gcp.project_id` and `cloud.account.id` resource attributes.
